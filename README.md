# 버는족족 — 공개 문서

iOS · Android 앱 **버는족족(moneybook)**의 공개 문서 저장소입니다.
앱 소스는 별도의 비공개 저장소에 있습니다.

- 📄 **[개인정보처리방침](https://chanho1124.github.io/moneybook-privacy/)** — [`index.md`](./index.md)
- 🗑️ **[계정 삭제 안내](https://chanho1124.github.io/moneybook-privacy/delete)** — [`delete.md`](./delete.md) (Google Play 계정 삭제 URL)
- 📲 **[다운로드](https://chanho1124.github.io/moneybook-privacy/download/)** — [`download/index.html`](./download/index.html) (앱의 "친구에게 추천하기"가 보내는 링크. 아이폰은 App Store로 바로 넘어간다. 안드로이드 정식 출시 후 `ANDROID_LIVE = true`)
- 🔗 **[초대](https://chanho1124.github.io/moneybook-privacy/join/)** — [`join/index.html`](./join/index.html) (공유방·챌린지 초대 링크. 초대 코드는 `#` 뒤에 실려 서버로 가지 않는다. 버튼을 누르면 `moneybook://join/...` 로 앱을 연다)
- 💬 **[고객지원](https://chanho1124.github.io/moneybook-privacy/support)** — [`support.md`](./support.md)

App Store · Google Play 심사에 내는 주소들이라, 고치면 위 주소에 바로 반영됩니다.
