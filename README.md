# 개인정보처리방침

**앱 이름:** 내돈어디
**최종 수정일:** 2026-09-20

내돈어디(이하 "앱")는 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」을 준수합니다.
이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

---

## 1. 수집하는 정보

### 가. 계정 정보
| 항목 | 목적 | 보관 위치 |
|---|---|---|
| 이메일 주소 | 로그인, 계정 식별 | Supabase (서버) |
| 비밀번호 | 로그인 인증 (암호화 저장, 복호화 불가) | Supabase (서버) |

### 나. 이용자가 직접 입력하는 정보
| 항목 | 목적 | 보관 위치 |
|---|---|---|
| 지출·수입 내역 (금액·카테고리·메모·날짜) | 가계부 기록 | **이용자 기기** + 서버 백업 |
| 영수증 사진 | 지출 기록 첨부 | **이용자 기기에만 저장** |
| 월 예산, 고정 지출 | 예산 관리 | **이용자 기기** + 서버 백업 |
| 소비 성향 설문 응답·결과 | 맞춤 소비 분석 | **이용자 기기** + 서버 백업 |
| 공유 가계부의 지출·채팅·표시 이름·프로필 사진 | 공유방 구성원 간 공유 | Supabase (서버) |

개인 가계부는 **이용자의 기기가 원본**이고, 서버에는 기기 변경·분실에 대비한
백업본이 저장됩니다. 기록에 첨부한 영수증 사진은 서버로 전송되지 않으므로,
앱을 삭제하거나 기기를 변경하면 사진은 복구할 수 없습니다.

### 다. 음성
마이크 버튼을 눌러 녹음한 음성은 **지출 내용을 글로 옮기기 위해서만** 사용됩니다.
녹음 파일은 처리 후 저장하지 않으며, 변환된 텍스트만 지출 기록으로 남습니다.

### 라. 결제내역·영수증 사진 (AI 자동 인식)
이용자가 직접 선택해 올린 **카드 이용내역·영수증 사진**은 그 안의 결제 건을
자동으로 읽어 가계부에 옮기기 위해서만 사용됩니다.

- 사진은 인식 후 **보관하지 않습니다.** 앱 서버와 AI 서비스 어디에도 저장되지 않습니다.
- 인식 결과에서 **카드번호 형태의 문자열은 저장 전에 자동으로 제거**됩니다.
- 사진을 올릴지는 이용자가 매번 선택하며, 올린 내용은 **저장 전에 화면에서 확인·수정**할 수 있습니다.
- AI를 쓰지 않고 직접 입력하는 방법을 항상 함께 제공합니다.

### 마. 자동으로 수집하지 않는 정보
앱은 위치 정보, 연락처, 사진첩 전체, 광고 식별자, 이용 행태 분석 정보를
수집하지 않습니다. 이용자를 추적하지 않습니다.

## 2. 제3자 제공 및 처리 위탁

앱은 아래 서비스에 정보 처리를 위탁하고 있습니다. 이 외의 제3자에게
개인정보를 판매하거나 제공하지 않습니다.

| 수탁자 | 위탁 내용 | 전송되는 정보 |
|---|---|---|
| **Supabase Inc.** | 계정 인증, 가계부 백업, 공유 가계부 저장 | 이메일, 가계부 기록, 공유방 지출·채팅·프로필 사진 |
| **Google (Gemini API)** | 글·음성·사진을 지출 항목으로 변환, 소비 분석 | 입력한 문장 · 음성 · 결제내역 사진, 카테고리 목록, 월 지출 합계 |

Gemini API로 전송되는 내용에는 **이메일이나 계정 식별자가 포함되지 않습니다.**

> **무료 등급 이용 시 유의사항**
> 현재 앱은 Google Gemini API의 무료 등급을 사용합니다. 무료 등급에서는
> 입력한 내용이 Google의 서비스 품질 개선에 사용될 수 있습니다.
> **민감한 내용이 담긴 사진은 가리고 올리시거나, 직접 입력 기능을 이용해 주세요.**
> 앱은 AI를 처음 사용하기 전에 이 사실을 안내하며, 동의해야 전송이 시작됩니다.

## 3. 보유 및 파기

- **계정 정보**: 회원 탈퇴 시 즉시 삭제됩니다.
- **가계부 백업**: 회원 탈퇴 시 함께 삭제됩니다.
- **공유 가계부 데이터**: 탈퇴 시 참여 기록이 삭제됩니다. 다만 공유방에 남아 있는
  다른 구성원을 위해, 이미 기록된 지출 내역은 작성자 표시 이름과 함께 방에 남습니다.
  본인이 만든 공유방은 다른 구성원이 있으면 가장 먼저 참여한 구성원에게 넘어가고,
  혼자였다면 방과 데이터가 함께 삭제됩니다.
- **기기 내 데이터**: 탈퇴 또는 앱 삭제 시 함께 삭제됩니다.
- **음성 녹음 파일 · 결제내역 사진**: 처리 후 보관하지 않습니다.

## 4. 이용자의 권리

이용자는 언제든지 다음을 할 수 있습니다.

- **열람·수정**: 앱 안에서 기록을 직접 확인하고 수정·삭제할 수 있습니다.
- **회원 탈퇴**: `설정 → 회원 탈퇴`에서 직접 처리할 수 있으며, 별도 문의 없이 즉시
  계정과 데이터가 삭제됩니다.
- **동의 철회**: 마이크·사진 권한은 기기 설정에서 언제든 해제할 수 있습니다.
  권한을 해제해도 직접 입력을 포함한 나머지 기능은 정상 이용 가능합니다.

---

## 5. 안전성 확보 조치

- 비밀번호는 복호화가 불가능한 방식으로 암호화하여 저장합니다.
- 서버와의 모든 통신은 HTTPS로 암호화됩니다.
- 공유 가계부 데이터는 데이터베이스 접근 제어(RLS)를 통해 해당 공유방
  구성원만 조회할 수 있도록 제한됩니다.
- 외부 AI 서비스 인증 키는 서버에만 보관하며 앱에 포함하지 않습니다.
- AI가 읽어낸 내용에서 카드번호 형태의 문자열은 저장 전에 제거합니다.
